# StudioPilot AI

StudioPilot AI is a creative workspace platform designed to help users create and manage different types of digital design projects in one place. The platform includes workspaces for website building, social media post editing, presentation and print design, and project organization.

This public repository is a project overview only. The source code is private.

## Overview

StudioPilot AI was built as a multi-workspace creative platform where users can create, save, edit, and manage design projects. The goal of the project is to make the design process easier by giving users a central workspace for templates, project editing, saved work, and export tools.

The platform focuses on usability, project organization, and workflow improvement. It includes different creative workspaces so users can work on websites, posts, flyers, resumes, presentations, and other design formats.

## Problem

Many creative tools separate different project types into different workflows. A user may need one tool for websites, another for social media posts, another for presentations, and another for print designs.

StudioPilot AI was created to bring these workflows into one platform so users can manage different creative projects from one dashboard.

## Analytics Feature 

A developer analytics dashboard is added to help understand how users interact with StudioPilot AI.

Analytics include:

* Most used project categories
* Template performance
* Most selected templates
* Most used fonts
* Most used colors
* Project creation trends
* Export activity
* Saved project activity
* User engagement patterns

This analytics feature will help identify which tools and templates users use the most, which project categories are most popular, and how the platform can be improved based on real user behavior.
